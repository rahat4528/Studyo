# Technology Stack

## Frontend Technologies
- **Next.js (App Router):** Server-side rendering, API routing, and optimized client bundles.
- **TypeScript:** Strict type enforcement across components and service layers.
- **Tailwind CSS:** Utility-first responsive design system.
- **Lucide React:** Accessible, lightweight UI iconography.
- **Recharts:** Client-side analytics visualizations and performance charting.
- **Monaco Editor:** Industry-standard browser code editing engine.

## Backend Technologies
- **NestJS & Express:** Structured enterprise backend frameworks with dependency injection.
- **Prisma ORM:** Type-safe database queries, declarative schema definitions, and migration tooling.
- **PostgreSQL:** ACID-compliant relational data storage with JSONB support and full-text search.
- **Redis & BullMQ:** Distributed in-memory caching and durable queue management.
- **Argon2 / BCrypt:** Cryptographic password hashing.

## Infrastructure & Testing
- **Docker & Docker Compose:** Containerized local dependencies (PostgreSQL, Redis, MinIO).
- **Jest & Supertest:** Unit, integration, and API testing framework.
- **Playwright:** End-to-end browser automation and user journey validation.
